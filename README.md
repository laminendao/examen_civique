# Examen civique – carte de résident

Entraînement quotidien aux 209 questions de connaissance officielles de l'examen civique (mention « carte de résident »).

- **Série du jour** : 15 questions, qui reprennent en priorité tes erreurs puis les questions jamais vues.
- **Examen blanc** : 40 questions au hasard, seuil de 32/40 (80 %).
- **Par thème** : les 5 thèmes de la liste officielle.
- **Révision** : toutes les questions avec leur réponse, avec recherche.

La progression est enregistrée dans le navigateur (localStorage).

## Mise en ligne sur GitHub Pages

1. Crée un dépôt public sur GitHub (ex. `examen-civique`).
2. Dépose `index.html` (et ce README) à la racine du dépôt.
3. Dans **Settings → Pages**, choisis la branche `main` et le dossier `/ (root)`.
4. Le site est disponible à `https://<ton-pseudo>.github.io/examen-civique/` au bout d'une minute environ.

Sources : liste des questions publiée par le ministère de l'Intérieur sur formation-civique.interieur.gouv.fr (licence Etalab 2.0). Les réponses ont été rédigées pour la révision.
